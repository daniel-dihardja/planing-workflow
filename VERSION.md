# Spec Version

Current spec version: `0.2.0`

## Versioning rules
- Increment `MAJOR` for breaking spec changes.
- Increment `MINOR` for backward-compatible spec additions.
- Increment `PATCH` for clarifications, wording fixes, or typo-only changes.
